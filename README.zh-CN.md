# Folivyn

Folivyn 是一款轻量、原生的 macOS 文本与代码编辑器。打开文件，完成修改，继续手头的工作。

[English](README.md) · **简体中文**

Folivyn 是一个由个人开发、持续完善中的项目。欢迎通过 [GitHub Issues](https://github.com/Amoo1121/Folivyn/issues) 反馈问题、提出建议，帮助它变得更好用。

## 功能

- **多文件标签。** 同时打开多个文件，每个标签独立保留撤销记录、选区和滚动位置。
- **从磁盘重新加载。** 读取其他工具修改后的内容；有未保存的编辑时，可以取消、放弃修改，或另存副本后再重载。
- **本地语法着色。** 为 Python、Java、JavaScript、TypeScript、JSON、JSONC 和 Shell 提供基础着色；其他文本格式照常打开。
- **日常代码编辑。** 显示逻辑行号，支持跳转到行、按标签手动选择语法语言，以及多行缩进、行注释切换、当前行底色和有限范围的括号提示。
- **查找与替换。** 使用原生查找栏，在当前标签内进行字面文本搜索、切换匹配及替换。
- **Finder 空格预览。** 内置扩展提供只读源码与语法着色。Python、JSON 已通过真实 Finder 空格键验证；其他类型使用哪个预览器取决于 macOS 和已安装应用。
- **CSV 与 TSV 表格。** 字段始终作为文本显示，支持逗号/制表符选择、可选表头与单元格编辑，并共用文档的撤销记录。
- **JSON 导航。** 源码旁显示可折叠树，支持键值搜索和无歧义的 JSON Pointer 复制；保留重复键及数字的原始写法。
- **本地草稿恢复。** 定期保存未保存正文的恢复快照，中断后可恢复为独立标签，不会覆盖原文件。
- **有限文件预览。** 大文件显示明确标注的只读前缀；二进制或无效文本显示无法预览提示，并可主动选择用默认应用打开。
- **谨慎处理文件。** 保留支持的编码、BOM 与换行。保存前检查外部变更，遇到冲突时提示处理。
- **完全离线。** 编辑与着色无需账号、网络或下载语言包。没有遥测或在线服务。
- **原生、小巧。** 使用 Swift、AppKit 和 macOS 系统框架，无第三方包依赖。

## 构建与运行

需要运行 macOS 14 或更高版本的 Apple Silicon Mac，以及包含 Swift 5.9 或更高版本的 Xcode。macOS 14 实机兼容性验证尚待完成。

```sh
git clone https://github.com/Amoo1121/Folivyn.git
cd Folivyn
./scripts/build-app.sh
open "build/Folivyn.app"
```

脚本构建 arm64 Release 应用并进行本地签名。存在 `/Applications/Xcode.app` 时会自动使用；也可通过 `DEVELOPER_DIR` 指定其他 Xcode 安装位置。本地构建没有经过 Apple 公证。

## 使用

| 操作 | 快捷键 |
| --- | --- |
| 新建文件 | `⌘N` |
| 打开文件 | `⌘O` |
| 保存 | `⌘S` |
| 另存为 | `⇧⌘S` |
| 从磁盘重新加载 | `⌘R` |
| 关闭标签 | `⌘W` |
| 查找 / 替换 | `⌘F` / `⌥⌘F` |
| 下一个 / 上一个匹配 | `⌘G` / `⇧⌘G` |
| 查找选中的文本 | `⌘E` |
| 上一个 / 下一个标签 | `⇧⌘[` / `⇧⌘]` |

标签名称旁的圆点表示有未保存的修改。状态栏显示编码、语言、路径及检测到的外部变更。文件事件会更新外部变更提示，包括原子替换；应用重新激活及保存前也会检查磁盘文件，重新加载由你手动执行。

### 界面语言

默认语言为英语，内置简体中文。界面跟随 macOS 语言偏好，不支持的语言回退为英语。全部翻译随应用提供。

### 支持的文件

- 最大 **10 MiB** 的文本文件，支持 UTF-8（含或不含 BOM）以及带 BOM 的 UTF-16 LE/BE。
- 不超过 **200 KiB** 且不超过 **20,000 行** 的文本提供基础着色；更大的文档仍可按纯文本编辑。
- CSV/TSV 表格支持最多 **5 MiB** 解码后 UTF-8 文本、**100,000 条记录**、**256 列**及 **250,000 个字段**。所有值均为文本，不执行公式、不推断数字类型；缺失字段需要在源码中添加。
- JSON 树支持最多 **1 MiB** 解码后 UTF-8 文本、**128 层嵌套容器**及 **100,000 个值**。树只读，修改在源码中完成；结构无效或超过预算时仍可编辑源码。JSONC 暂只提供源码视图。
- Quick Look 最多读取 **200 KiB** 编码文本或 **2,000 行**，截断时明确提示，拒绝无效编码与二进制控制字符。预览不会修改或执行文件。

主窗口可对更大的文件提供最多 **200 KiB** 或 **2,000 行**的只读预览。预览标签不能编辑、保存或另存；重新加载会读取新的前缀。二进制或无效编码会显示无法预览，不会用替换字符强行解码。符号链接保存到其目标；存在多个硬链接的文件需要另存。保存前会检查外部修改，但其他进程同时写入仍可能在最终检查与替换之间产生竞态。

### Finder 预览

先运行构建后的应用，再在 Finder 选中支持的文件并按空格。使用本扩展时，预览顶部会显示 **Folivyn · 只读预览**（英文界面为 **Folivyn · Read-only preview**）。macOS 可能选用其他已安装的预览器；当前测试机器上的 CSV 由 Numbers 接管。Folivyn 不会更改默认打开方式。本地构建注册、已验证类型与限制见 [Quick Look 验证记录](docs/quick-look-validation.md)。

### 结构化文件

CSV/TSV 默认以表格打开。双击已有单元格可编辑完整内容（包括字段内换行），点击“应用”写入文档。表格用 `↵` 显示换行，文件中的原文保持不变。“源码”视图可直接编辑文本；切换视图、分隔符和首行表头都不会重写文件。

JSON 默认并排显示源码与树。选择节点可定位原始 token，选择源码可定位所属节点；搜索后用“上一个/下一个”导航。重复键路径不能唯一标识一个值，因此禁用 JSON Pointer 复制。

### 日常编辑

“文件 → 最近打开”可重新打开已成功读取的文件。将本地普通文件拖入窗口会走同一打开流程；文件路径不会被插入正文或 CSV 单元格草稿。每次最多接收 32 个拖入文件。

使用 `⌘L` 跳转到逻辑行；自动折行不会重复编号。状态栏显示已有换行类型，“混合换行”不会被自动转换。“编辑 → 转换换行符”可显式将整个文档的 CR/LF/CRLF 转为 LF、CRLF 或 CR；一次撤销即可恢复，转换不会自动保存文件。在“编辑 → 语言”可为当前标签覆盖扩展名识别，或选择纯文本。`⌘]` / `⌘[` 增加 / 减少四空格缩进，`⌘/` 切换当前语言的行注释；JSON 和纯文本不猜测注释语法。

保存/另存面板支持选择 UTF-8、UTF-8 BOM、UTF-16 LE/BE BOM，默认保留文档原编码。普通保存继续使用该编码；取消面板不会更改正文或文件。选择编码不会自动统一换行。

### 草稿恢复

停止输入约 750 毫秒后，未保存正文会生成本地恢复快照；持续输入时最长合并窗口为 5 秒。下次启动可选择“全部恢复、稍后处理、丢弃恢复副本”，也可从“文件 → 恢复草稿”重新打开列表。恢复标签是独立的未保存副本，首次保存需要选择位置；原路径与编码只作为提示。将文件正文删空后也能恢复。

快照位于 `~/Library/Application Support/Folivyn/Recovery` 私有目录，单份上限 32 MiB、总量 256 MiB、最多 128 份。保存、重新加载或明确关闭文档后会清理其恢复副本；取消多标签退出会保留草稿。最近的按键、未确认的输入法组合和未应用的 CSV 单元格草稿可能尚未写入快照，因此恢复不能替代保存，也不保证抵御存储故障。

## 开发

运行文件处理、编辑会话与本地化测试：

```sh
env DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  swift test --scratch-path build/TestBuild
```

代码分为 `EditorApp`（AppKit 界面）、`EditorUI`（共享着色与界面字符串）和 `EditorCore`（文件访问与文本模型）。本地化字符串位于各 target 的 `Resources/en.lproj` 与 `Resources/zh-Hans.lproj` 目录。

已验证的文件处理与编辑流程、禁网检查及验证边界见[原生验收记录](docs/native-validation.md)。
CSV/JSON 编辑、导航和剩余验证项见[结构视图验证记录](docs/structured-views-validation.md)。
