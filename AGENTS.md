# Folivyn development instructions

- Read and follow [CONTRIBUTING.md](CONTRIBUTING.md), especially the code and asset provenance requirements.
- Implement project behavior independently. Do not copy, translate, or disguise another editor's implementation or paste external snippets into this repository.
- Keep the current Swift/AppKit implementation free of third-party package dependencies and bundled external assets. References to possible libraries in design documents are research, not authorization to import them.
- When future work calls for an external component, document the source, pinned version, license, compatibility, and required notices before integration. Exclude material with unknown or unsuitable rights and continue with an independent implementation where possible.
- Preserve copyright and license notices. Treat generated code as requiring review, not as evidence of originality. Record known external sources in the change description.
- Do not claim that automated scanning proves worldwide originality or absence of infringement. Report the files and history reviewed, evidence found, and remaining limits.
- Keep all app features offline, preserve file safety, and maintain English plus Simplified Chinese localization. Package the root LICENSE with the app.
