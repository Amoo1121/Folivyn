## 1. 产品目标

做一款文件优先的原生 macOS 工具：从 Finder 打开一个文件，就能快速看懂、定位和修改，不必先建立项目。

首版聚焦代码与文本编辑、CSV 表格、JSON 树，以及 Finder 空格键语法预览。“大部分文件”指常见代码、配置、日志和文本文件，不承诺编辑任意二进制格式。

暂定支持 macOS 14 及以上，优先验证 Apple Silicon。底层编辑和解析复用成熟组件；当前候选为 NSTextView / TextKit 2 与 tree-sitter，正式选型须通过原型验证。

### 当前 P0：先把打开、编辑与重载做好

原型保持小范围：纯 Swift/AppKit 与系统框架，不引入第三方运行时或远程依赖。

- 打开、编辑、保存和另存文本；多个文件在同一窗口以 tab 切换，分别保留内容、选区、滚动位置、撤销记录和未保存标记。关闭未保存文件时提示处理。
- 提供“从磁盘重新加载”（Reload）。无本地修改时重读文件；有未保存修改时可取消、放弃修改后重载，或先另存副本再重载。读入成功后才替换内容，失败保留当前文本；重载清理旧撤销记录，并尽量保留选区和滚动位置。
- 窗口重新激活时检查外部修改，保存前再核验；发现冲突时提示，不能静默覆盖磁盘新版本。P0 不做持续文件监听或日志追踪。
- 使用原生文本输入、选择、撤销重做；为 Python、Java、JavaScript/TypeScript、JSON/JSONC 和 Shell 提供简单的本地语法着色。着色只辅助阅读，不宣称语义诊断或完整语法解析。
- CSV/JSON 在 P0 中先作为文本编辑；专用表格/树、Quick Look、草稿恢复、更多语法与完整代码编辑辅助仍保留在 V1，不作为这次原型的交付前提。

### 全阶段约束

全部功能必须能完全离线使用：不需要账号、联网激活、远程解析、运行时下载语法包、遥测或自动更新。V1 和后续扩展也不能以网络服务提供必需能力；语法与必要资源随应用打包。网络盘文件本身的可访问性不属于应用离线能力。

应用体积优先精简：复用系统框架，按需纳入语法资源，不捆绑浏览器、语言运行时或项目索引服务。P0 的 arm64 Release `.app` 初始预算为 **≤15 MiB**；当前实测文件总大小 262.90 KiB、磁盘占用 288 KiB，不包括开发工具与构建缓存，也不代表完整 V1 体积。为节省体积而移到首次启动下载不符合离线要求。

## 2. 核心使用流程

- 在 Finder 选择支持的文件，按空格获得带语法高亮的只读 Quick Look 预览。
- 通过“打开方式”、应用打开对话框或拖放进入编辑器；是否设为默认打开方式由用户主动决定。
- 普通文本直接进入编辑区；CSV 默认呈现表格并可切换源码；JSON 呈现源码与可折叠树导航。
- 视图解析尚未完成时仍可阅读源码。解析失败时显示位置和原因，并保留源码编辑能力。
- 修改后保存；发现磁盘文件被其他程序更改时明确处理冲突，不静默覆盖。

## 3. V1 文件能力

| 文件类别 | 计划能力 | 首版边界 |
| --- | --- | --- |
| 常见代码、配置、Markdown、日志、纯文本 | 编辑、行号、语言选择、语法高亮、查找替换、跳转 | 语法高亮不包含代码执行、类型诊断或智能补全 |
| CSV / TSV | 源码与表格切换、字段定位、单元格编辑 | 先支持逗号与制表符；不执行公式、不自动推断数字或日期 |
| JSON | 源码编辑、树折叠、键和值检索、树与源码互相定位 | 树负责阅读和导航；修改在源码区完成 |
| 无扩展名文本 | 检测文本、手动指定语言与编码 | 扩展名只是提示；编码无法可靠解码时不得静默替换字节 |
| 超大文本或复杂结构 | 在预算内预览，必要时关闭高亮或进入只读模式 | 降级门槛由原型实测确定，界面说明当前限制 |
| PDF、图片、Office、数据库、压缩包及其他二进制 | 明确说明当前不支持，提供系统打开入口 | 首版不包含预览或编辑；PDF、图片只读预览可列后续 |

V1 首批语法覆盖优先选择 Python、Java、JavaScript / TypeScript、JSON、YAML、TOML、Shell、Markdown、C / C++、Swift、Go、Rust、SQL 和 XML / HTML / CSS；最终清单以语法包兼容性、体积预算与验收结果确定，P0 采用上文的小范围着色。

## 4. 文档与视图的一致性

每个文件只有一个文本真源、一套版本号和一套撤销记录。源码、CSV 表格和 JSON 树都是同一文档的不同呈现。

派生视图来自明确的文档版本。后台解析结果过期时不得应用；结构视图过期或无效时不得继续据此修改文本。用户修改源码后，专用视图自动更新。

打开、切换视图、折叠树或改变表头显示都不会改写文件。不得为了显示专用视图而重新序列化整个文件；未修改的原文应保持原样。

### CSV / TSV

- 表格采用虚拟化展示，避免为所有单元格创建界面元素。
- 单元格修改只替换对应字段的原文范围，正确处理引号、转义及字段内换行，并进入文档撤销记录。
- 所有字段按字符串处理：`00123`、长账号、日期样式内容和 `=SUM(...)` 均不自动转换或执行。
- 保留未修改部分的分隔符、引号、BOM、换行及末尾换行；区分空字段、缺失字段和末尾空列。
- “首行作为表头”只影响显示。分隔符不明确时提供选择，明确方言后才允许表格写入。
- 行宽不一致可展示实际存在的字段；缺失字段占位不可直接编辑。解析失败时降级源码编辑。
- 首版不做增删行列、多单元格粘贴、公式、自动类型转换或保存排序结果。

### JSON

- 树与原文范围对应，选中树节点可定位源码；源码修改后更新树。
- 重复键保留每次出现，大整数和浮点数保留原始词面，不能因转成字典或浮点数而丢失信息。
- 无效 JSON 保持源码可编辑，显示解析错误；不自动修正或格式化。
- JSONC 可先作为源码编辑；树不支持其语法时明确提示，不移除注释。
- 首版树不提供结构写入、键重命名或节点拖动，后续通过保留格式的局部修改机制扩展。

### Finder Quick Look

- 作为 V1 必交付入口，放到 P0 之后验证扩展注册、支持类型、语法高亮与真实 Finder 调用。
- 首版提供支持类型的只读源码预览，不要求在预览窗口交付可编辑 CSV 表格或 JSON 树。
- 支持范围按实际注册与验收的文件类型公布，不承诺拦截所有文本或无扩展名文件。
- 对超大或异常文件限制工作量，给出可读结果或清晰降级；预览不修改文件，不执行文件内容。

## 5. V1 完整性要求

- 文件打开、拖放、多标签、最近文件；遵循 macOS 常用快捷键和窗口行为。
- 保留 P0 的手动重载及冲突处理，重载不得丢失未经确认的本地修改。
- 中文输入、选区、撤销重做、基本查找替换、行号与跳转。
- 显示编码和换行状态；编码转换由用户明确触发，不能通过保存隐式完成。
- 安全保存、外部修改检测、未保存内容恢复；恢复草稿不能直接覆盖更新的磁盘版本。
- CSV 表格和 JSON 树与源码保持一致；Finder Quick Look 达到已公布类型的验收要求。
- 提供可解释的资源降级，不以卡住界面的方式等待解析完成。

## 6. 主要风险与验收原则

| 风险 | 必须验证的结果 |
| --- | --- |
| 编码与格式损失 | 未修改文件保存后字节不变；局部编辑不重写无关字段、键或换行 |
| 并发修改与保存身份 | 外部更改不被静默覆盖；符号链接、权限和文件元数据有明确行为 |
| 撤销与恢复分裂 | 源码和单元格修改可一致撤销；异常退出后恢复正确版本 |
| Unicode 与输入法 | 中文组合输入、Emoji、复杂字符下选区、字段范围和撤销正确 |
| 解析与渲染失控 | 超长行、深层 JSON、巨大 CSV 和连续编辑下仍可取消、降级和交互 |

## 7. 分阶段交付

1. **P0 小型原型：** 验证多文件 tab、文本输入与保存、重载与冲突、基础着色、完全离线和安装体积；当前实施范围以上文 P0 清单为准。
2. **V1 可日常使用：** 交付本规格的三种编辑/阅读体验、Quick Look、文件流程、可靠性和降级能力，通过验证路线中的发布门槛。
3. **后续扩展：** 根据使用反馈增加文件夹搜索、Markdown 预览、PDF/图片只读预览，再评估 CSV 批量操作与 JSON 树编辑。

首版不包含项目索引、终端、调试、插件、Git 面板、AI 或 LSP；只有经实际需求证明有价值后才进入后续规划。
